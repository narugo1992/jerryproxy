# Security Policy

JerryProxy is pre-alpha and has not published a stable release. Report
vulnerabilities through GitHub private vulnerability reporting when available;
do not include live subscription credentials or provider bodies in a public
issue.

Security-sensitive areas include backend download integrity, archive
extraction, active-link replacement, state permissions, subscription
redaction, controller authentication, and process identity validation.

External backends retain their own security policies and licenses. A bug in an
upstream core should also be reported to that upstream project when doing so
does not expose JerryProxy user credentials.
