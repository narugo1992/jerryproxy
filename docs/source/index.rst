JerryProxy
==========

JerryProxy is a Python 3.7+ multi-backend proxy CLI and backend manager.

.. warning::

   JerryProxy is pre-alpha. The current runtime slice accepts bounded
   ``V2RAY_SUBSCRIPTION`` SS/VMess/VLESS URI sources and runs Mihomo 1.19.29 in
   the foreground. Native profiles, additional cores, controllers, and
   measurements remain work in progress.
