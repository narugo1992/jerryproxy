JerryProxy
==========

JerryProxy is a Python 3.7+ multi-backend proxy CLI and backend manager.

.. warning::

   JerryProxy is pre-alpha. Backend installation/version switching exists;
   subscription and proxy runtime orchestration remain work in progress.
